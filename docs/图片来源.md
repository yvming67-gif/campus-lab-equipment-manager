# 资源照片来源与授权

## 当前发布状态

当前网页和小程序不分发第三方实验室照片。资源目录与登录页使用明确标记的“暂无本项目实验室实拍图”占位；不以图库照片、生成图或其他学校图片充当本项目房间或设备实拍。后台暂未开放房间图片上传，避免在没有授权、隐私和对象归属核验流程时收集或公开图片。

此前静态目录曾打包中南大学自动化学院公开报道中的三张照片。来源网页为[中南大学自动化学院实验室开放日报道](https://soa.csu.edu.cn/info/1031/8984.htm)及[具身智能联合实验室报道](https://soa.csu.edu.cn/info/1031/9791.htm)，访问日期2026年11月8日。公开页面能够支持“该学院公开展示了若干实验室及相关设备”的事实；网页可浏览不等于授予图片再分发许可。旧图片未获得独立许可证明，因此已从当前网页和小程序包中删除。

**公开历史边界：** 旧提交`c7af090`仍是当前公开`origin/main`的祖先，其中包含`static/photos/`与`miniprogram/assets/photos/`下的三张图片副本（`csu-laboratory.jpg`、`csu-robot-controls.jpg`、`csu-robot-platforms.jpg`）。因此删除当前文件并未撤回GitHub上可浏览的历史版本字节。根据此前保留公开提交历史的决定，本轮不改写历史；这不表示历史图片获得了新的授权。若要求这些文件不再通过GitHub历史访问，必须另行决定是否变更该历史保留要求并执行历史重写与强制同步。

## 新增照片准入记录

每张拟新增图片必须登记：资源编号、拍摄者或来源、是否为该资源实拍、权利人、许可条款或书面授权、授权范围与期限、是否含可识别人员/屏幕/敏感设备信息、页面说明、访问权限、替代图和撤回方式。只有授权范围覆盖本项目的部署和展示场景，且图片确实对应所选资源，方可加入公开静态目录或受控附件存储。

后续如启用后台上传，应限制实验室管理范围、图像格式和大小，剥离不必要的定位元数据，记录上传和替换审计；替换图片不得覆盖历史业务凭据。没有授权或不能确认对应关系时继续显示“暂无本项目实拍图”。

### 管理字段与发布流程预留

下表是后续经学校确认后可用于 `RoomPhoto` 档案的候选业务字段，不表示这些字段已经加入数据库或当前已开放上传。因目前没有本项目授权实拍图，本期不新增照片实体、文件存储或管理页面；候选存储位置、文件容量、格式白名单、保留期限和公开范围应在确定学校责任岗位、部署存储和隐私要求后再定。

| 候选字段 | 业务含义 | 发布前校验 |
| --- | --- | --- |
| `resource_id` | 照片对应的唯一房间资源 | 必须是当前管理范围内的场地资源；不能把其他学校图片挂到模拟房间 |
| `asset_key` | 受控存储中的文件标识 | 不直接接受任意外部URL；上传、下载、删除均检查对象授权和当前访问范围 |
| `caption`、`alt_text` | 画面说明及无障碍替代文本 | 说明照片内容和实景/示意属性，不披露未批准的人员、屏幕或安全信息 |
| `source_type`、`creator_or_source` | 来源类别、拍摄者或来源机构 | 记录来源；不得仅以“网页可访问”作为转载许可 |
| `rights_holder`、`license_or_authorization_ref` | 权利主体与许可/书面授权凭据引用 | 凭据应覆盖网站/小程序、公开/受控展示、期限及必要的修改/裁切范围 |
| `authorized_from`、`authorized_until`、`allowed_channels` | 授权起止及可展示渠道 | 到期或渠道不匹配时自动撤下公开显示并保留撤回记录 |
| `privacy_review_status`、`privacy_reviewed_by`、`privacy_reviewed_at` | 人员、屏幕、敏感设备或定位信息的检查结果 | 发布前由授权岗位核验；检查失败或待复核不得标为可公开 |
| `publication_status`、`published_by`、`published_at` | 草稿、待复核、已发布、已撤回等状态及责任 | 上传者不得独立批准自己的公开发布；发布和撤回记录不可覆盖 |
| `is_primary`、`sort_order`、`withdrawal_reason` | 展示顺序、主图标记及撤回原因 | 同一资源最多一个当前主图；历史记录仍能追溯，但撤回文件不可继续访问 |

建议流程：范围授权的管理员提交房间照片及来源凭据 → 系统校验目标资源和管理范围 → 有权复核人检查授权、对应关系及隐私 → 仅在授权范围内发布 → 授权到期、争议或隐私风险时立即撤下并记录原因。替换、撤回和重新发布应形成新版本或新档案，不静默覆盖旧凭据。不得把本候选流程描述为已实现功能；启用前还需评估私有存储访问、大小/格式验证、元数据清理、备份恢复及各端缓存失效。

## 视觉与案例资料的区别

公开高校网页可用于研究实验室类型、组织和教学场景；其照片不能作为本项目模拟房间的档案资料。案例来源、访问日期、支持事实和适用边界见[案例研究与设计决定](案例研究与设计决定.md)。
