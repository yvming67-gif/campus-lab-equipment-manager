# 工作台、日程与移动端优化

本轮基于用户指定的产品参考改进既有校园实验室演示系统，保留Django/PostgreSQL与原生微信小程序。业务范围仍为设备借用和教师整间场地预约，未扩展到医疗业务。学校现状仍来自课程题设和既有业务假设，本轮研究不构成实地调研。

## 参考依据与取舍

2026-10-24实际只读登录[DentalPin演示站](https://demo.dentalpin.com/)，查看工作台、Settings、Workspace、People及日程。其可取之处是把当天任务与长列表分开，把资源空间、开放安排、人员授权和通知组织为可发现的管理分类。只观察了前端行为，无法据此声称其后端如何实现事务或并发；没有复制代码、商标、界面素材或演示患者记录。

[Open Dental预约模块](https://www.opendental.com/site/0_appointments.html)将日期视图、待确认清单与实际到场分开呈现；[开放安排](https://www.opendental.com/site/0_schedule.html)和[安全配置](https://www.opendental.com/site/0_security.html)分别说明日历例外、角色和审计。本项目将这些组织方法映射成实验室日程、待办和职责边界，未引入患者、收费、保险或治疗项目。

指定的[数据库结构XML](https://www.opendental.com/OpenDentalDocumentation26-2.xml)已下载解析，根版本26.2.0.0，共430个table元素。抽样检查预约、资源、排班、用户组、权限、审计、字典和任务等表的列与说明，借鉴编号关联、安排与事实分离、停用保留历史的思路。本轮未修改校园领域数据表，因此既有ERD、数据库迁移和课程业务基线继续适用；不把规模更大的医疗模型当作应有复杂度。

已阅读[试用安装说明](https://opendental.com/site/trial.html)，未安装另一套医疗软件及MySQL/MariaDB。现有文档、XML与演示页面已足够支持本轮取舍。完整来源、限制和XML摘要见参考来源登记.json。

## 网页使用变化

登录后，管理员从工作台进入审核、复核、今日交接、超期未结束、异常核实和维修验收队列。每个队列仍以授权实验室和实际可办理条件筛选。历史维修参与者不能进入可独立验收队列，但仍能查看本人有权访问的历史任务。个人预约卡片和“我的记录”只查看本人数据。

资源日程同时呈现当日开放带、已确认计划、使用中与暂停交接标记。待审核不占资源时段，日程不公开申请人、用途或预约编号；计划结束不伪造实际归还。日程空白只是没有显示已确认占用，不能替代资格、配额、固定设备依赖及提交时冲突检查。日期筛选支持1900—2100年查看，预约创建仍遵守既有14天窗口；每页20项资源。

管理中心按设备与场地、实验室与开放日历、用户与授权、角色与培训目录分类。实验室管理员不能因能维护资源而查看全部用户授权；系统管理员也不能因能配置账号而取得审批、交接或验收权。角色目录解释既有权限，未开放任意新增角色代码。实验室目录、每周日历版本与单日例外分别分页，可按有权实验室、关键词和日期范围查询全部匹配记录。日历版本按日期交集筛选，单日例外仅列当前生效版本。

网页左下角账号齿轮直达管理中心；窄屏导航默认折叠，保留键盘焦点与跳到正文链接。管理数据表在自身容器内横向滚动，不让整页被长表格撑宽。

## 小程序使用变化

首页可查看本人下一次已确认或使用中的预约；待复核记录提醒暂停交接。状态数量可进入对应的本人预约列表。资源查询可选目标日期和起止时段，结果明确显示实际查询时段，进入详情时携带该时段；未确认提交的草稿仍优先恢复。编辑条件后继续翻页会回到新查询第一页，旧响应不能覆盖新结果。

通知提供服务端未读筛选，避免只筛当前加载页面。“我的”展示本人培训资格、当前有效性和到期时间；实际申请还须覆盖整个预约时段。资格列表采用唯一code标识，同名培训类型不会使用重复渲染key。

后端地址继续由开发者配置，普通登录者不能改动；与云端、网页共用事务服务。新增API字段向后兼容，不改原预约状态或接口路径，不增加Node构建作为日常运行前提。

## 交付与验证边界

建设与27个既有系统用例的对应见建设与需求对应.json和implementation_map.json。本轮不改变审批分级、待审核占用、配额、实际交接、独立维修验收和审计不可覆盖的规则。

独立子agent审查、问题编号、自动检查及网页尺寸证据见同目录验证与独立复核.md和问题修正记录.json。实际环境为Windows、本地隔离PostgreSQL与模拟数据。本轮手机流程按用户要求暂停；历史Android反馈、当前编译检查与未来真机验收分别记录，iPhone延期。学校身份、微信订阅消息、合法域名、平台名称审核及真实云端联合恢复等既有外部边界未因本轮建设而宣告完成。

实际发布、远端检查及官方预览构建结果见[发布与验证结果](发布与验证结果.md)。

继续建设修订了管理目录分页和个人概览独立反馈，最新阶段结果见[继续建设记录](继续建设记录.md)。
