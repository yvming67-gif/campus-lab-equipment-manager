## 发现即记录的细节问题

### CONT-01 概览失败提示错误地指称数字位于下方

- 类型：已确认缺陷，轻微，代码确认；仅为位置文案不准确，不影响数字及加载状态。
- 对应：AUD-0099 配套反馈遗漏。
- 位置：`miniprogram/pages/resources/index.wxml` 的 overviewError 提示，审查初始第 5 行。
- 触发：已有成功概览后再次 /me/ 失败。
- 实际：提示“下方预约数字和使用安排为上次成功结果”，但三个预约数字位于提示上方 hero，只有使用安排在下方。
- 预期：用户能识别哪些数据未刷新，不依赖错误的方位词。
- 建议：删除“下方”，写“预约数字和使用安排为上次成功结果”。
- 验收：核对 WXML 顺序与新提示文字；旧数据保留及错误独立状态测试仍通过。
- 状态：已即时通知主 agent；最终修订状态见末尾追加记录。

### CONT-02 新检索条件下的两个空状态仍沿用旧语义

- 类型：已确认缺陷，轻微，代码确认；两处具有相同根因，合并记录并逐一保留位置。
- 对应：AUD-0098 配套检索反馈遗漏。
- 位置一：`templates/management_directory.html`，实验室目录的 empty 分支。
- 条件与实际：管理员有授权实验室，但关键词无匹配时，仍显示“暂无授权实验室”，将检索零结果表达为没有权限范围。
- 位置二：同文件，单日例外 tbody 的 empty 分支。
- 条件与实际：用户检索历史日期范围且没有例外，仍显示“暂无后续单日例外”，与当前检索日期不一致。
- 预期：空状态准确说明筛选结果，不误述授权状态或时间方向。
- 根因：增加关键词及历史日期筛选后，未同步旧空状态文案。
- 建议：分别改“暂无匹配的有权实验室，请调整筛选条件”和“所选日期范围内暂无生效例外”。
- 验收：关键词无匹配、历史无例外时出现相应提示，权限与分页逻辑保持不变。
- 状态：已即时通知主 agent；最终修订状态见末尾追加记录。
