# 免费额度与停用策略

演示使用免费资源，额度不足时接受相应服务暂停，不自动升级套餐、购买额外用量或增加付费基础设施。网站固定地址不意味着无条件持续在线。

## 各类额度分别核对

- Render免费Web实例会在闲置后休眠；免费实例小时耗尽时按平台规则暂停服务。流量、构建分钟与实例小时属于不同额度。
- 支付方式、超额费用及构建支出上限由账号所有者在私有账单界面核对；本项目不提供已生效的账户级零费用保证，也不公开个人账单或支付资料。
- Neon计算、网络、数据库空间和对象存储分别查看当前套餐条件；周期额度与长期存储容量不能混淆。存储不会因月度额度更新自动清空。
- 告警和应用限流可降低消耗，不能替代平台费用硬限制。发现需要付费验证或升级时，由所有者核实，不默认接受。

## 运行安排

不使用持续保活请求掩盖休眠。后台在服务恢复后按幂等规则补扫，但不能追溯承诺休眠期间实时送达。纯文档提交可使用 `[skip render]` 避免不必要构建；运行代码变化需正常部署并核对目标版本。

暂停计算服务和删除数据库不同。不得为节省额度直接删除预约、审计、附件或备份。恢复服务后先核对健康状态、后台补扫、关键记录和附件权限，再继续演示。
