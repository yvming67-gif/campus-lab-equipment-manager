# 界面与交互契约

网页与微信采用浅色层次、圆角和少量透明工具区域；正文、密集表格与长表单使用稳定背景。CSS/WXSS效果不是Apple原生Liquid Glass。品牌为墨绿烧瓶与“校园实验资源中心”。

| 目标 | 当前行为 | 业务边界 |
| --- | --- | --- |
| 查询上下文 | 条件摘要、单项清除、目录与公开日程往返、近期日期导航 | 非法格式不执行查询，不暴露他人身份与用途 |
| 可用性 | 分开显示服务状态、实物状态、目标时段结果及审批方式 | 未选择时段不能宣称可交付；候选是快照，不预留 |
| 审批效率 | 待审时长、用途摘要、按权限检查资格和冲突 | 页面旧结果不能替代批准时重新校验 |
| 预约详情 | 状态、负责岗位、下一步与已登记交接地点 | 不虚构联系人；计划到期不伪造实际归还 |
| 文字报告 | 补充说明只追加；普通报告与安全阻断按领域规则区分 | 不自动定责、赔偿或认定维修完成 |
| 显示偏好 | 网页支持玻璃开关及工作人员紧凑视图；微信“我的”可简化透明与动态效果 | 不支持模糊时使用实色，不改变授权 |
| 失败反馈 | 字段错误指出原因；空结果、加载失败、网络结果未知分别表达 | 未知结果保留请求标识和内容，先核对原记录再重试 |

## 角色—任务—界面—权限映射

首页差异按工作目标和服务端权限组织，不表示不同角色拥有相同数据范围。角色与权限基线见[系统需求](specification.json)及[角色工人与实体目录](逻辑整改/角色工人与实体目录.md)。

| 角色 | 首页优先任务 | 主要入口 | 权限和边界 |
|---|---|---|---|
| 学生 | 查询设备、空闲时段、安全信息；处理个人预约与借还 | 资源目录、资源日程、我的预约、通知 | 只看本人业务记录；不能申请整间场地；不得查看其他申请人的用途和身份 |
| 教师 | 安排设备与整间场地；查看课程场地进度和实际交接 | 资源目录、场地预约、我的预约、场地开始/结束进度 | 可申请场地和设备；场地批准后仍须由授权管理员登记真实开始、结束 |
| 实验室管理员 | 处理授权范围内的待审申请、现场交接、异常核实和独立验收 | 待审核队列、今日交接、待归还、异常与维修 | 服务端按管理单元授权；不得审批本人申请；维修执行人员不得验收本人维修 |
| 维修人员 | 处理分配给本人且仍开放的维修工单 | 我的维修任务、工单详情、维修结果提交 | 只能查看指派给自己的任务及必要证据；提交维修完成不等于恢复资源可预约 |
| 实验教学中心主任 | 查看已授权范围内的利用、等待和异常趋势 | 利用率报表、审计摘要 | 只读；统计依赖明确口径与已记录数据，不取代审批、交接或异常处置 |
| 系统管理员 | 维护账号、身份映射、角色和基础配置 | 用户与授权、资格及配置目录 | 系统管理身份本身不赋予业务审批、设备借还或维修验收权限 |

以上映射已用角色工作区自动化测试检查主要标题和任务入口，并对服务端既有访问规则进行回归；本轮没有完成所有角色的浏览器截图走查、320/390/768/1440像素视觉验收或新小程序真机验收。角色页面的真实信息密度与岗位流程仍需目标组织用户走查。

主要触控区按至少44逻辑像素设计，不把44rpx等同于44像素。状态同时显示文字，不仅靠颜色。查询帮助层只组织受控站内链接和显示元数据，不决定可用性和权限。

筛选和记录恢复必须限定当前用户及来源，身份变化不展示旧用户信息。小程序接口及回执见[接口与通道](接口与通道.md)，实际验证范围见[验证说明](验证说明.md)。
