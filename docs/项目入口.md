# 网站与微信入口

## 在线网页

打开[网页登录入口](https://campus-lab-equipment-manager.onrender.com/access/)，选择「进入系统」，输入账号和密码。学生使用 `student` 或 `student2`，教师使用 `teacher`，公开密码为 `Demo@2026`。同一公开账号共享预约记录、消息与配额。

以下账号从同一个网页入口登录。已获仓库访问权限的用户可在[云端岗位账号与密码](../README.md#云端岗位账号与密码)查看各自的密码。

| 账号 | 工作台 |
| --- | --- |
| `student_lab` | 我的实验预约 |
| `teacher_lab` | 课程资源安排 |
| `admin` | 实验室运营 |
| `tech` | 维修工作台 |
| `sysadmin` | 系统设置 |
| `director` | 中心概览 |

查看[按角色操作指南](演示操作说明.md)了解预约、审批、借还和维修流程。也可打开[网站与小程序说明页](https://campus-lab-equipment-manager.onrender.com/access/)。免费服务休眠后的首次访问可能等待约一分钟。云端暂时不可用时，可参照[Windows 本机运行指南](运行指南.md)。

## Windows本机账号

下载并完整解压仓库，双击 **启动演示.cmd**，打开启动窗口中的网址。以下七个账号使用本机默认演示密码 **`Demo@2026`**。

| 本机账号 | 角色 |
| --- | --- |
| `student`、`student2` | 学生 |
| `teacher` | 教师 |
| `admin` | 实验室管理员 |
| `tech` | 维修人员 |
| `sysadmin` | 系统管理员 |
| `director` | 实验教学中心主任 |

本机与云端各自保存模拟记录。云端岗位账号使用部署方配置的独立密码。详见[Windows 本机运行指南](运行指南.md)和[按角色操作指南](演示操作说明.md)。
