# 网站与微信入口

## 在线网页

打开[网页登录入口](https://campus-lab-equipment-manager.onrender.com/login/)，点击「选择演示账号」。学生使用 `student` 或 `student2`，教师使用 `teacher`，公开密码为 `Demo@2026`。同一公开账号共享预约记录、消息与配额。

以下账号从同一个网页入口登录，各自的密码由部署方私下提供。

| 账号 | 工作台 |
| --- | --- |
| `student_lab` | 我的实验预约 |
| `teacher_lab` | 课程资源安排 |
| `admin` | 实验室运营 |
| `tech` | 维修工作台 |
| `sysadmin` | 系统设置 |
| `director` | 中心概览 |

查看[按角色操作指南](演示操作说明.md)了解预约、审批、借还和维修流程。也可打开[网站与小程序说明页](https://campus-lab-equipment-manager.onrender.com/access/)。免费服务休眠后的首次访问可能等待约一分钟。云端暂时不可用时，可参照[Windows 本机运行指南](运行指南.md)。

## Windows本机账号

下载并完整解压仓库，双击 **启动演示.cmd**，打开启动窗口中的网址。以下七个账号使用本机默认演示密码 **`Demo@2026`**。

| 本机账号 | 角色 |
| --- | --- |
| `student`、`student2` | 学生 |
| `teacher` | 教师 |
| `admin` | 实验室管理员 |
| `tech` | 维修人员 |
| `sysadmin` | 系统管理员 |
| `director` | 实验教学中心主任 |

本机与云端各自保存模拟记录。云端岗位账号使用部署方配置的独立密码。详见[Windows 本机运行指南](运行指南.md)和[按角色操作指南](演示操作说明.md)。

## 微信公开版

**目标使用方式：**正式发布并开放搜索后，在微信内搜索“实验设备预约助手”即可进入，不要求访客扫描体验二维码或先加入体验成员。账号名称审核、备案、代码版本审核、正式发布和搜索设置都完成前，这个名称还不是可保证使用的公开入口。

最近一次已独立核实的后台记录（2026年11月6日）尚未公开发布；此后用户报告新账号名称审核仍在进行，但该情况未由本项目独立登录后台核实。备案截图仅能证明打开了资料填写页面，不能证明已经提交或审核通过。开发/体验版本只用于发布前核对，体验码有平台有效期且受成员权限限制，长期访问以正式版为准。正式版上线并确认未授权体验成员也能通过微信搜索进入后，再把微信入口标记为可用。平台状态及准备事项见[微信发布说明](微信发布说明.md)。页面品牌、账号名称审核、备案、版本审核、正式发布和搜索设置分别管理。

共享演示仅使用模拟身份与数据。
