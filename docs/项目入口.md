# 网站与微信入口

## 公开网站

- 网站：[校园实验资源中心](https://campus-lab-equipment-manager.onrender.com/)
- 固定访问说明页：[网站与小程序入口](https://campus-lab-equipment-manager.onrender.com/access/)

网页供所有访客使用模拟身份体验。管理操作按角色授权，账号及流程见[操作说明](演示操作说明.md)。免费实例休眠后的首次访问可能等待约一分钟，额度耗尽或故障时服务可能暂停；固定地址不是全天候可用保证。

公开入口提供学生和教师账号。管理员、维修人员、系统管理员和中心主任使用独立的[评审入口](https://campus-lab-equipment-manager.onrender.com/review/)，由部署方启用后持访问码登录。评审账号操作共享模拟数据。

**使用方式：**网页日常访问直接打开上方固定网址，不需要登录 GitHub 或扫描二维码。免费托管可能休眠或达到额度上限；若访问延迟，稍等服务唤醒后重试。

## 微信公开版

**目标使用方式：**正式发布并开放搜索后，在微信内搜索“实验设备预约助手”即可进入，不要求访客扫描体验二维码或先加入体验成员。账号名称审核、备案、代码版本审核、正式发布和搜索设置都完成前，这个名称还不是可保证使用的公开入口。

最近一次已独立核实的后台记录（2026年11月6日）尚未公开发布；此后用户报告新账号名称审核仍在进行，但该情况未由本项目独立登录后台核实。备案截图仅能证明打开了资料填写页面，不能证明已经提交或审核通过。开发/体验版本只用于发布前核对，体验码有平台有效期且受成员权限限制，不作为教师或日常访客入口，也不会作为GitHub首页入口。正式版上线并确认未授权体验成员也能通过微信搜索进入后，再把微信入口标记为可用。平台状态及准备事项见[微信发布说明](微信发布说明.md)。页面品牌、账号名称审核、备案、版本审核、正式发布和搜索设置分别管理。

共享演示只使用模拟内容；公开密码见[首页](../README.md)。不要填写真实隐私、密码、联系方式或责任材料。
