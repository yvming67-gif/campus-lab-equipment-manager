# 访问入口与预约流程

本轮从 Andrew Dental 的公开首页和演示工作台提取了两项设计思路。首屏用清楚的主行动和分类入口承接访客目标。资源详情和结果页分别回答选什么、何时使用、接下来谁负责。实际查阅了参考站的手机导航、门诊详情、三步指引、预约列表与日程、牙椅资源和资质目录。

|改进|实现与验证目标|
|---|---|
|访问入口|公开页面分为进入系统、设备、教室三个入口。受保护目录先登录，完成后继续进入原分类。跳转限于指定的站内资源目录。|
|角色登录|在统一网页入口直接填写账号和密码。角色及其职责见项目 README。|
|资源卡片|教室显示房间号、位置、容量和当天或所选日期的开放安排。设备显示交接地点、培训要求和确认方式。开放安排和目标时段可用性分别展示。网页点击整张卡片或用键盘激活资源名称可进入详情。有权限时可通过「查看时段」直接跳到详情的选时区。|
|预约步骤|选资源与时段、核对并提交、查看结果与下一步。网页和小程序复用原预约与审批规则。网页结果未知时，同一浏览器标签页保留原请求及输入，可先核对回执并按原内容重试。|

首页标题和资源入口分段入场，预约说明和资源目录卡片首次进入视口时短暂淡入。参考站的实拍背景影像属于其自身素材，本项目使用轻量界面动画。系统开启减少动态效果时关闭这些入场动画。 登录后，各角色工作台采用同样的短入场和滚动动效。「使用说明」可以悬停预览，也可以通过触屏或键盘打开。

图片仅采用已登记且允许公开展示的对应资源实拍。当前未取得可新增的对应实拍授权。网页无需扫码。微信公开发布、真机及审核状态需要单独验证。

参考：[Andrew Dental 首页](https://andrewdental.top/) · [门诊目录](https://andrewdental.top/explore/clinics) · [预约指引](https://andrewdental.top/#booking)。

## 验证记录

- 隔离 PostgreSQL 的网页实测覆盖教师从教室快捷入口经原角色卡片登录（历史验证）并返回教室目录。六间教室都显示开放安排。320、390、768、1440 CSS 像素的教室目录未出现整页横向溢出。
- 使用真实网页表单提交普通设备、受限设备和教室三类申请，分别显示等待现场领取、等待审核和等待审核。核对区显示已填用途与人数。模拟浏览器恢复验证了原内容、编号和回执入口。
- Django 定向回归通过105项，随后补测双端开放日期一致性和回执对象范围，2项通过。小程序128项客户端测试与8页编译通过。独立复核后修正回执恢复、设备交接点和日期摘要问题。
- 微信开发者工具已核对师生登录、六间教室、开放摘要和预约详情。复跑原生控件后核对了前两步，并在同一隔离库的教师预约结果页看到第三步及等待审核。正式版和真机留待单独验证。
- 改为手动输入账号和密码后，在隔离 PostgreSQL 中复跑登录与权限检查，15 项通过。本机 Chrome 下，320、390、768、1440 CSS 像素的登录页均无整页横向溢出。教师输错密码后页面保留账号、清空密码，重输正确密码后进入原教室目录。

## 动态待审看板

网页实验室管理员在工作台点击预警分组进入筛选后的待审队列，点击申请行直接进入预约详情。工作台展示全部可处理待审的数量，以及未来两小时内按预约开始时间排列的最多五条记录。短条图显示各预警组占全部可处理待审的比例。模拟数据环境会标注数据性质。

| 指标 | 统计口径（北京时间） |
|---|---|
| 优先处理 | 尚未开始，且距开始不超过 60 分钟的待审核申请 |
| 即将开始 | 距开始大于 60 分钟且不超过 120 分钟的待审核申请 |
| 全部可处理待审 | 授权实验室内尚未开始、由他人提交的全部待审核申请 |

同一申请在同一快照中最多进入一个预警组。所有计数和预览共用一个查询时点。超过开始时间的申请退出看板，状态由现有后台任务处理。两小时提示在看板展示，站内提醒使用既有触发口径与去重规则。

工作台在可见且活跃时每 60 秒刷新，可手动刷新，重新进入时读取新数据。后台标签页及五分钟没有交互的页面暂停轮询。临时失败保留最近一次成功结果和时间戳。服务端确认会话失效或权限不足时清空快照。鼠标悬停申请行可看摘要，触屏或键盘可操作「摘要」，Esc 可关闭。系统减少动态效果设置关闭短条过渡与摘要入场动画。

### 看板验收记录

- PostgreSQL 独立测试库中通过 112 项定向回归，覆盖 60 和 120 分钟边界、跨实验室权限、排除本人申请、会话权限、队列筛选、真实提交和审核。
- Chrome 双会话在单独数据库中提交教室预约，管理员看板计数从优先处理 0、即将开始 0、全部待审 1 更新为 0、1、2。每五秒观察一次时，在约 61.6 秒看到新结果，同次浏览器快照请求约 72 毫秒。完成原审核流程后重新进入，看板显示 0、0、1，预览清空。测试时钟设在开放时段，数据为模拟记录。
- 通过 320 CSS 像素窄屏、鼠标悬停、键盘、减少动态效果及断网恢复检查。在另一个标签页退出后，旧工作台收到 HTTP 401 并清空待审数据。
- 本机热连接连续计算 20 次快照，业务数据查询每次一条，计算中位数约 2.42 毫秒。该测量不包含认证、网络、并发负载或 Render 冷启动。
