# 运行指南（Windows 10/11）

## 准备条件

使用Windows 10/11的x64电脑、现代浏览器和Python 3.13的Windows 64位版本。首次初始化需要可访问Python包索引及EDB官方下载的网络，以及约2GB可用磁盘空间。Python安装入口：[Python官方Windows下载](https://www.python.org/downloads/windows/)，安装时勾选“Add python.exe to PATH”；已装Python 3.13启动器的电脑也可直接使用。

本项目使用真实PostgreSQL，因此不以SQLite或纯前端假数据替代数据库。启动器自动安装私有便携组件，无需手动创建数据库、安装系统服务、配置GitHub账户或输入数据库密码。默认只监听本机回环地址。

## 从GitHub下载到首次运行

1. 打开 https://github.com/yvming67-gif/campus-lab-equipment-manager 。
2. 点击绿色“Code”→“Download ZIP”。下载后先完整解压到本地，如`D:\课程验收\校园实验室项目`，不要在压缩包预览窗口中运行。中文与空格路径受支持；建议使用普通本地目录。系统优先使用Windows短路径；禁用短路径且用户临时目录含中文时，会尝试公共文档或系统临时目录中的可写英文联接目录，业务数据仍留在项目内。
3. 进入含README、manage.py及“启动演示.cmd”的项目根目录，双击“启动演示.cmd”。
4. 等待窗口完成依赖、约364MB官方PostgreSQL下载、数据库初始化、迁移、模拟主数据和网页检查。进度会显示在窗口，首次运行时间随网络而变。
5. 浏览器自动打开登录页。通常为 http://127.0.0.1:8000 ；若被占用会选择随后空闲端口，以启动窗口的“启动成功”地址为准。
6. 点击“进入统一身份入口”，选择账号并输入演示密码`Demo@2026`。这些公开账号均为模拟示例，未接入真实学校认证。

|账号|演示职责|
|---|---|
|student、student2|设备查询、预约、取消及本人记录|
|teacher|设备及整间场地预约|
|admin|审批、设备借还、场地交接、异常确认、维修指派和验收|
|tech|被指派维修的过程与结果|

## 建议验收顺序

先以student预约未来开放时段的普通设备，观察自动确认，再取消。申请受限设备后切换admin审批；用teacher申请场地并由admin批准。场地与室内设备不会相互自动占用，学生不能预约整间场地。其余异常、维修和报表流程见[演示操作说明](演示操作说明.md)。

真实时钟执行08:00—20:00开放规则。要立即演示借还，可在项目根目录PowerShell运行：

```powershell
.venv/Scripts/python.exe manage.py prepare_demo
```

这会补充当前开放时段可交接的模拟记录；开放时间以外会给出说明，不修改电脑时间。随后按页面提示核对模拟身份、设备标签和配件。不要把“当前不在开放时间”当成安装失败。

## 停止与再次启动

演示时保留启动窗口。在该窗口按Ctrl+C停止网页和任务；再双击“停止数据库.cmd”停止本项目数据库。再次双击启动会复用本项目数据，保留预约、审计和角色调整。安装好的环境在常规本地演示时不再下载组件。

`.venv`为独立Python依赖，`.local`为随机密钥、数据库和日志。这两个目录不会从作者电脑带入GitHub，首次运行会在本机生成相应内容；不要删除它们以处理普通报错。已初始化后若要移动目录，应先停止全部进程；推荐重新下载源码并初始化独立演示环境。

## 常见问题

- **提示找不到Python**：安装Python 3.13的64位版本，关闭并重新打开终端；启动器先尝试`py -3.13`，再检查`python`。
- **PostgreSQL组件无法运行或缺少DLL**：安装微软官方Visual C++ 2015—2022 x64运行库：[Microsoft运行库说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。安装系统组件可能需要电脑管理员许可；不要从不明网站下载DLL。
- **下载中断或网络超时**：检查网络后再次启动。已完成且SHA-256校验通过的数据库压缩包会复用，不会重新初始化已有数据库。文件校验失败会停止执行并提示具体文件。
- **默认端口被占用**：数据库和网页会各自选择空闲端口，使用窗口显示地址；不会把另一项目的数据库当作本项目数据库。本项目私有数据库配置优先，不会被电脑上已有的PGUSER等环境变量覆盖。也可以在PowerShell指定`python tools/start_local.py --setup --port 18000 --db-port 55440`。
- **提示没有可写英文运行目录**：这是系统目录权限受限时的回退提示。先在自己有写权限的磁盘建立纯英文目录，例如`D:\CampusLabTemp`；在项目根目录PowerShell临时执行以下命令，仅影响当前终端：

```powershell
$env:TEMP = 'D:\CampusLabTemp'
$env:TMP = $env:TEMP
python tools/start_local.py --setup
```

若电脑没有D盘，换成自己的可写英文路径。无需删除已有数据，也不修改系统范围的环境变量。

- **浏览器未自动打开**：复制窗口“启动成功”后的完整地址到浏览器。
- **启动失败**：窗口会保留错误提示，先查看`.local/web.log`、`.local/jobs.log`、`.local/postgres.log`。不要提供`.local/database.json`或`.local/keys.json`中的密码和密钥。

## 自助复验

验证真实安装和HTTP就绪后自动停止网页、后台的命令：

```powershell
python tools/start_local.py --setup --no-browser --smoke-test
```

正常显示PASS后，可双击启动入口进行页面验收。安装完成后运行自动化规则与并发测试：

```powershell
.venv/Scripts/python.exe manage.py test core.tests --noinput
.venv/Scripts/python.exe tools/test_startup.py
.venv/Scripts/python.exe tools/validate_registry.py
```

业务测试创建独立测试库，不清空演示库。GitHub中Linux上的业务检查和Windows上的首次安装检查用于跨环境复验；实际执行结论见[测试与验收记录](测试与验收记录.md)。同一台机器上的干净副本验证不等于实测每一台Windows 10/11电脑，真实校园认证和邮件短信也不在本地演示范围内。
