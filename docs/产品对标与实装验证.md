# 产品对标与实装验证

2026年11月13日从本地 `main` 的 `54a317b` 建立对照。网页实测使用同一套隔离 PostgreSQL 模拟资料和六个普通网页登录角色。公开参考系统的操作限于登录和浏览。

## 采用的改进

|任务及对比依据|原系统表现及证据|改动与验收|
|---|---|---|
|主任从工作台读统计范围，核对 Open Dental 的权限和报表文档|浏览器首页标“31天”，而默认日期随当前时刻计算。代码使用 UTC 零点作起点，提交相同日期后会重新按本地零点解析。|统一北京时间最近七个日历日和当前截止时刻，31天仍是自选区间上限。输入非法时显示具体错误。以北京午夜后的固定时刻验证首次进入与重提日期的窗口相同。对应 UC-24、BR-34、AC-47/48。|
|管理员从工作队列定位一笔申请，参考独立日程与工作列表的组织方式|同一笔模拟申请按编号可以搜索，搜索结果只显示资源编号；经办人需打开详情才能核对申请编号。队列中可有未来记录。|队列和通用记录行显示同一预约编号，首页入口标“预约与交接”。查看同一模拟记录的前后截图并检查授权范围。对应 UC-26。|
|教师继续缩小自己的教室申请列表，参考按资源和条件定位的高校指南|浏览器从 `scope=mine&kind=ROOM` 进入，输入搜索词后 `kind` 消失，可混入设备记录。|表单保留场地条件，可从筛选标签单独清除。浏览器提交前后核对请求和当前筛选。对应 UC-26。|
|教师小程序按容量找教室，学生先查设备|两类身份原先使用相同目录标题和设备默认页；教师需先切到场地，再展开容量条件。|教师首屏可直接进入教室筛选，学生首屏聚焦设备和个人进度。继续使用原目录和权限字段；客户端回归验证学生不触发该捷径、教师查询参数为场地。对应 UC-02。|
|师生查看适用于该资源的安全要求|网页已隐藏空安全区块，小程序还会在无发布规程时显示占位段落。|小程序与网页统一隐藏空区块，有发布内容时仍显示适用版本与阅读确认。对应 UC-02 与资源安全信息。|

### 实测与验证范围

- Chrome 普通登录分别进入我的实验预约、课程资源安排、实验室运营、维修工作台、系统设置和中心概览。场地目录实际显示3组各2间教室，保留两间独立资源、容量和日历的设计。教师选教室、核对容量和候选时段并提交，实验室管理员从同一业务入口核对条件及批准，状态由待审核转为已确认并提示等待入场。
- 系统管理员在隔离库把迟到宽限改为20分钟，重新打开表单核对了保存结果。主任检查报表及审计页。模拟样本不代表学校制度。
- 学生从示波器候选时段带入表单，实际保存后为已确认，经本人取消后显示已取消。管理员也在网页批准了一笔受限摄影设备申请。
- 在 Chrome 的320、390、768、1440 CSS 像素下核对中心概览、报表、审计、待审队列、管理中心及教室目录。24个页面与宽度组合无整页横向溢出。键盘首个跳转链接有可见焦点，玻璃开关在有模糊支持的 Chrome 中生效。
- 小程序128项客户端测试通过，8个页面的 WXML、WXSS 通过编译。官方微信开发者工具基础库3.17.6连接隔离后端，学生登录并加载设备目录，教师通过原生控件进入教室查询并加载6间教室。Android真机和正式版暂未复验，iPhone按既定安排暂缓。
- 用隔离库的时段夹具从网页实际办理设备借出、异常归还、工单指派、维修结果提交及独立验收。维修由处理中转为待验收，管理员验收后关闭。完整链路亦可通过 `core.demo_identity_tests.PublicDemoIdentityTests.test_private_student_and_staff_complete_equipment_workflow_through_web` 复跑。此次业务规则和物理模型没有新增字段或迁移。
- 按 CI 选择的业务模块和云端配置模块在隔离 PostgreSQL 回归，Django 运行385项，383项通过、2项跳过。另行尝试的10万预约记录 HTTP 负载测试出现请求超时，未取得达标结论。独立复核定位了教师筛选、报表错误反馈和小程序入口差异，均已修正并定向复验。
- Word 报告同步 UC-24 与 UC-26。Microsoft Word 更新目录和图录后仍为176页 A4。全页渲染与上一版比较，视觉变化限于两页目录和四页相关正文，变化页已逐页复核。
- 发布、设备和运行证据分开记录。微信体验及正式发布需以官方平台及普通微信账号实测为依据。
- 推送后，Render 的 `/health/` 返回 ready。首次访问曾遇到加载页、502 和超时，唤醒后公开教师账号正常登录，并在「本人场地预约」筛选表单查到本轮新增的资源类型字段。公开站点只读取页面。该行为确认网页改动已生效，Render 的部署提交号未从后台独立读取。
