# 使用边界与待验证事项

本项目目前适合课程本地演示及受控共享体验；没有据此证明可直接替代真实学校现行管理。以下条件影响使用和结论。

| 方面 | 当前边界 | 应用前需要完成的工作 |
| --- | --- | --- |
| 业务依据 | 现状来自课程题设，没有真实学校访谈、问卷或观察 | 确认岗位、场地固定设备关系、教学优先与例外处理制度 |
| 身份与权限 | 使用公开模拟账号，接口保留真实身份适配契约 | 接入并验收学校身份、离校停用、培训与管理范围维护 |
| 通知 | 站内通知与模拟外部投递，不是微信订阅消息或短信 | 确认真实渠道、用户授权、重试与送达责任 |
| 免费云端 | 闲置休眠，休眠期间后台任务暂停；额度耗尽接受暂停 | 按目标服务时间核定计算及调度条件，不作全天候承诺 |
| 备份与恢复 | 本地恢复及模拟存储测试不等于真实Neon和私有桶联合恢复 | 在隔离目标演练关键记录、附件摘要和会话失效，确认RPO/RTO |
| 微信入口 | 最近一次有后台证据的版本记录为2026年11月6日：1.4.0体验版、1.4.1准备包上传、request域名已配置；之后未重新核验后台 | 核对当前版本、合法域名、基础资料、备案、代码审核及公开发布状态；分别保存后台证据 |
| 名称与发布 | 页面品牌“校园实验资源中心”与平台登记名称分开；用户后来指定目标名称“实验设备预约助手”。新主体审核状态未独立核实 | 以当前微信后台为准确认名称、类目和备案；不得沿用旧测试账号的名称驳回结论，也不以页面标题宣称通过 |
| 手机验证 | 历史Android预览有核心流程；近期包仅局部确认显示、登录、入口及候选布局 | 新包完整写入、异常、断网回执等需独立复验；iPhone延期 |
| 实景照片 | 当前网页、小程序与公开静态目录不再分发第三方实验室照片；没有本项目资源的授权实拍图 | 获取真实资产前保持占位；上线前逐张核验资源对应、权利范围、隐私与撤回流程 |
| 共享数据 | 演示身份公开，访客会共同改变同一批模拟记录 | 禁止真实敏感材料；正式服务需独立身份、隐私及保留政策 |

预约规则和默认数值是已确认的课程约束，不是目标学校制度。人员值守、审批时限、维修响应与争议处置仍需组织确认。测试覆盖有边界，不能宣称已发现或排除所有潜在缺陷。
