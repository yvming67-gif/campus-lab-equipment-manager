# GitHub首页改版

首页按“项目与演示范围—界面预览—业务场景—快速开始—角色账号—规则—技术结构—正式材料—验证问题—部署维护”组织。顶部使用现有墨绿烧瓶标识，链接分两行以避免窄屏词组断开，保留官方工作流状态徽章。徽章只反映既有自动检查，不能解释为无缺陷或全部场景验收通过。

网页截图采用已经公开的本地模拟环境图，注明不是真实学校运行或微信真机截图；ERD大图放入可展开区域，主要阅读入口改为矢量总图和A4图册。角色账号、报告、模型和运维材料采用表格索引，降低连续长段落的查找负担。

将完整开发、测试、数据库迁移与备份命令移入[开发与验证](../开发与验证.md)。首页仍提供在线演示、Windows下载运行和小程序导入入口，明确云端默认连接不需要本机启动。本机样本准备与共享云端数据维护分开，未新增用户角色、系统模块或功能承诺。

使用GitHub官方Markdown API按仓库上下文解析，确认5张表和1个可展开区正常生成；以本地检查样式查看1440和390宽度的渲染内容，修正了窄屏导航末字单独换行。该预览不是实际GitHub网页截图，样式与GitHub主题可能不同。最终远端发布状态应以GitHub提交与工作流结果为准。

首次预览检查脚本错误要求字面量`<table>`，而GitHub输出带`role="table"`，导致脚本断言失败；已按真实HTML标签处理，没有为脚本改变有效表格。另对渲染输入按LF文本计算摘要，与Windows原始CRLF字节摘要分开；不将换行差异误判为内容变化。证据见[渲染摘要](证据/README渲染.json)。

本次已将最新审查入口置于首页，说明仍有待处理问题，不以排版改善掩盖审查结论。正式Word、ERD与应用界面未由首页改版改写。
