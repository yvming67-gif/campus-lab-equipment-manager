# 网站页面核查

主流程使用agent-browser专用Chromium会话访问本机隔离模拟站点，未操作共享云端业务。六个角色为学生、教师、实验室管理员、维修人员、系统管理员和中心主任；另有匿名登录页。已完成82次页面/视口观察，覆盖桌面1440×1000与手机宽度390×844。

所测页面未出现整页横向溢出、可见input/select/textarea缺少可访问名称或损坏图片。该结论由DOM观察和代表截图复核组成，不表示82次均逐像素检查、全部浏览器无问题或屏幕阅读器验收通过。表格自身滚动与整页溢出分别看待。

|范围|已实际读取|
|---|---|
|匿名与身份|登录页、模拟身份往返、六角色工作台及角色切换|
|资源|目录、设备详情、教师场地详情、日程与资源/类型筛选入口|
|预约|本人/管理员列表、无匹配查询、设备与场地预约详情|
|异常与维修|异常列表、新异常表单、维修任务列表；没有新造维修事实来填充空页面|
|管理|概览、资源目录/新档案、实验室日历、用户授权、角色培训、政策/每周日历/实验室与单日例外表单|
|通知与审计|站内通知、外部投递页、只读审计、主任报表、系统运维摘要|
|权限拒绝|学生管理/审计/报表、维修人员管理/报表、主任管理、系统管理员业务报表，看到中文权限拒绝与返回入口|

网页截图直接复核代表包括admin工作台、手机日历、director报表、手机资源目录。全量路径、角色、视口、可见控件及文字摘要见[逐页观察](证据/网页逐页观察.json)，机器摘要见[观察摘要](证据/网页观察摘要.json)。截图采用模拟数据，数量不表示学校实际业务量。

原本地预览数据保留；为现场详情可见性使用prepare_demo在本机模拟库新增了两份明确标注的样本，不修改电脑时间或共享云端数据。仅启动隔离网页与数据库，没有据此宣称全部后台任务持续运行。

最初两次自动化因URL通配等待不匹配而停在实际已到达的页面；更换为实际登录表单/工作台文字等待后完成全部观察。中断跨回合后本地服务已停止，先核实后恢复同一数据目录。以上是工具和隔离环境过程，不当作网站功能失败。

未执行：本轮云端完整设备借还/维修闭环、所有隐藏组合表单、真实手机浏览器、Safari/Firefox/Edge差异、键盘全流程和屏幕阅读器；真实数据长文本、生产压力和免费实例长时间运行也未由本次页面读取覆盖。后端输入/权限/并发与小程序网络问题的反例单独记录，不以页面布局正常盖过这些问题。
