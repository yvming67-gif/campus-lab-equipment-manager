# 发布前体验版

本项目最终目标为公开正式小程序，当前体验版只用于发布前核对，不作为所有人均可访问的正式入口。

2026年11月6日，开发版本1.4.0通过官方工具上传，并在平台版本管理中选为体验版，默认页面为pages/login/index。实际生成的二维码由平台标注“11月13日前有效”，未把它提交为公开永久入口。

现有云端已保存为request合法域名。体验成员及手机正常校验访问仍需分别核对；开发工具关闭域名检查不是正式配置证据。iPhone延期。

成员授权由账号管理员按实际使用者添加，不将普通使用者提升为开发者。长期公开访问应完成正式发布，参见[微信发布说明](微信发布说明.md)。源码导入见[开发指南](../miniprogram/README.md)。
