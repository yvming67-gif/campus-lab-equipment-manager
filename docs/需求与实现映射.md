- P-01 信息分散且查询依赖管理员 → I-01 集中资源档案、开放日历与目标时段可用性查询 → FR-02、FR-03、FR-18

- P-03 纸质与共享表格重复录入，普通申请等待人工确认 → I-03 一次录入、分级确认与本人进度查询 → FR-04、FR-05、FR-06、FR-26
- P-04 审批结果散落即时消息，缺少连续责任记录 → I-04 在线决定、补充说明、原新状态与操作者审计 → FR-06、FR-08、FR-21
- P-05 到场核验与配件核对缺少准备，领取排队 → I-05 按确认预约办理，核验身份标签和交接清单，采集等待时间 → FR-09、FR-10、FR-11
- P-06 归还、异常与维护状态不同步 → I-06 归还事实、异常隔离、维修验收和状态同步形成闭环 → FR-10、FR-12、FR-13、FR-14、FR-15、FR-16、FR-17、FR-18、FR-25
- P-07 场地使用结束与设备归还混记，责任不清 → I-07 场地独立申请，教师负责，管理员登记实际开始与结束 → FR-05、FR-11、FR-12
- P-08 提醒依赖电话且失败后无跟进 → I-08 站内通知与投递任务同事务保存，独立重试、人工联系留痕 → FR-06、FR-07、FR-08、FR-09、FR-10、FR-11、FR-12、FR-13、FR-14、FR-15、FR-16、FR-17、FR-22、FR-23

- P-10 身份、培训资格与管理范围核查不一致 → I-10 统一身份映射、最小角色权限、实验室范围和资质复核 → FR-01、FR-04、FR-05、FR-08、FR-09、FR-11、FR-18、FR-19、FR-20、FR-21、FR-25
