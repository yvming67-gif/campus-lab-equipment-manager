## 三、发现与处理对应

### 1. 演示说明把所有报障一律隔离

- 原位置：`docs/演示操作说明.md` 初始第7步。
- 冲突：原文字“上报资源异常后会隔离资源”；specification UC-13及BR-22、DOCX P1507、ERD第2页均区分普通无关联报告先核实与安全/关联事实阻断。
- 影响：演示者可能把普通报告后的NORMAL误认为系统失效，或按错误流程预期验证。
- 建议/归属：按分级规则写清记录、核实、阻断、维修与独立验收，作为 AUD-0052 的遗漏实例，学校制度问题仍与 AUD-0005 区分。
- 修订后初核：已写明普通无关联报告先核实，安全或关联事实按规则阻断；验收人还须未实际参与工单维修。没有新增制度或改变代码。

### 2. 小程序安装与平台资料说明仍沿用早期阶段

- 原位置一：`docs/微信小程序扩展说明.md`“安装与验证依据”首段，原写当前仅同机开发者工具本地演示。
- 原位置二：同文末段，原写平台名称和头像尚未修改。
- 原位置三：`docs/整改/待确认与外部依赖.md`第4项，原将测试号无编辑入口与最近资料未改作为当前结论。

- 影响：读者会重复寻找已移除的地址输入，或误以为必须恢复旧测试号；平台审核状态可能被错误传播。

### 3. 正式小程序登录说明缺少配置条件和错误顺序

- 原位置：`docs/微信小程序扩展说明.md`“身份、事务和边界”，原将DEMO_MODE=0简单表述为接口返回503。
- 代码证据：`core/miniapi.py` endpoint装饰器首先执行请求方法检查；非演示且未配置CAMPUS_MINI_IDENTITY_ADAPTER时统一503；已配置才进入login检查一次性code，字段不合法400，适配器异常503，无法映射有效学生/教师403。可配置接口不证明真实学校已接通。

### 4. 本机、云端和生产环境说明未充分分界

- 原位置：`docs/演示操作说明.md`首段、第1/5/10步：固定8000、准备命令、每23小时备份和.local目录没有充分限定本机；`docs/整改/生产部署边界.md`首段把HTTPS与未验收真实接入并列。

- 影响：可能在错误环境套用命令或把本机定时归档理解为云端持续恢复保障；也可能误读为尚无HTTPS演示。

- 修订后初核：演示说明已分环境，云端归档及运行恢复说明增加真实边界，生产说明限定为正式学校生产环境。
