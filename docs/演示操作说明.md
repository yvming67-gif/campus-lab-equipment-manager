# 演示操作说明

本项目可使用已有[云端演示](https://campus-lab-equipment-manager.onrender.com/)或在本机独立运行。两者各自保存模拟数据，不能把本机创建的预约当作云端已有记录。以下人员、设备、维修事实和业务均为模拟示例；本机专属命令不得对共享云端数据执行。

1. 云端演示直接打开上述地址；本机演示双击项目根目录“启动演示.cmd”，默认 http://127.0.0.1:8000 ，端口占用时以启动窗口实际地址为准。进入身份入口，以公开演示密码Demo@2026选择角色。
2. 用student查看资源目录。选择普通“数字示波器”，预约未来14天内同日08:00至20:00的30分钟整数时段，填写用途。应直接显示“已确认”。可在开始前取消。
3. 选择“全画幅摄影套装”或“协作机器人平台”，应进入待审核；机器人还检查模拟培训资格。切换admin，在预约记录中审核。不同申请可竞争，批准时再次检查。
4. 用teacher申请整间实验室，填人数；admin审核。场地申请不会把室内设备自动借出，学生场地申请会被拒绝。
5. 本机演示现场交接时可先运行prepare_demo命令（见README），只在自己的模拟库创建演示场景；共享云端不运行此命令。再用admin打开该环境当前已确认记录。设备借出现场编号为S-DEMO-02，标签EQ-SEN-01；核对配件、到场及办理时间后借出，再逐件办理归还。无借出、标签不符、缺件与逾期分别处理，不能伪造正常凭据。
6. 当前场地的负责教师编号T-DEMO-01，由admin登记人数和实际开始，结束时填写工位、设备环境及门禁检查。场地与设备有独立凭据。
7. 异常报告先形成可追踪记录。普通且无关联使用事实的报告先由admin核实；安全报告、有关联责任事实的异常及核实确认按既有分级规则阻断，不将所有报障一律隔离。需要维修时admin创建工单并指派tech；tech接单、追加过程、提交结果后为“待验收”，由具备权限且未实际参与本工单维修的管理员复测验收。验收不通过继续维修；其他异常或停用限制仍在时不能恢复资源。
8. sysadmin可修改预约参数与模拟消息失败开关。外部服务失败时，站内结果仍存在，最多3次重试（1、5、15分钟间隔）。失败任务可追加人工联系说明。后台需保持运行。
9. director可查看资源报表和审计，普通用户直接访问管理地址将被拒绝。实际利用率按历史正常开放时数计算，不把预约计划当成已使用。
10. 本机停止网页在启动终端按Ctrl+C；数据库可单独停止。本机启动器的后台在具备runtime.json时每23小时尝试备份，数据和归档保存在私有.local目录，重启不清空。云端数据保存在Neon数据库和私有对象存储，Render临时目录不能当作持久备份；免费实例休眠期间任务暂停，唤醒后补扫。真实云端联合备份与恢复仍待独立演练，不能用本机自动备份周期代替。

当前已初始化的2间实验室、8项设备、2间场地与7个模拟账号均用于课程展示。真实学校制度、培训证明、节假日安排、校园认证和消息提供方未接入。
