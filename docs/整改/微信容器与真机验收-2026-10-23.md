# 微信容器与真机验收记录

## 当前结论与版本边界

2026年10月23日，以提交`8c8b51e6518940532722a6cb4040c7cbc2e3b04d`为源代码基线进行分阶段验证。原预览已完成Android核心课程业务：原生登录、普通设备预约与取消、受限设备网页审批同步及取消、本人通知、学生场地权限、断网恢复和退出。设备实际操作来自用户反馈，关键预约状态、审批与通知由已部署网页或小程序接口独立核对。

随后按用户要求，将小程序内部品牌改为“校园实验资源中心”，加入墨绿烧瓶勾选图标，并移除使用者可修改后端地址的入口。首个品牌预览界面更新已由用户确认，但Android调试模式登录报告无法连接。修订版延长首次登录等待并细分网络提示，客户端37项及7页模板编译通过；用户使用最新二维码明确确认“已进入资源目录”。该结果证明修订版在本次Android测试号调试条件下可登录，不证明最初失败一定由超时造成，也不等于修订版全部业务场景重新执行。

AUD-0037继续为“等待外部环境验证”：完整容器场景、iPhone、非调试模式、合法域名及平台发布尚未完成。微信最近列表中的账号名称、头像未修改；用户在当前测试号申请页及主平台测试号登录后均未找到基本信息编辑入口。内部品牌设置不等同平台资料修改。

## 环境和方法

官方开发者工具Stable 2.02.2608080、基础库3.17.4、miniprogram-automator 0.13.0。安装包已核验腾讯签名。容器使用独立Django/PostgreSQL模拟数据；手机使用已部署HTTPS演示。Android运行时报告HUAWEI FIN-AL60a、Android 12、微信8.0.78。模拟器显示的iPhone机型不计为真实iPhone证据。

手机操作由用户执行，审查者核对服务端结果；未声称远程自动化代替物理操作。新预览副本只有项目元数据与公共源码不同，运行文件一致。测试号AppID、二维码、会话、账号后台信息不进入公开仓库。

基础库缓存rename曾报EXDEV和本地脚本500。早期跨磁盘猜测未证实，后续源与目标均在C盘；按同一官方URL下载原字节并放到缺失缓存后可初始化，未修改基础库。窗口最小化、后台节流、旧会话跳转、脚本把undefined误判完成、错误CDP窗口选择、SDK弹窗及事件回执超时均有记录，不能统一归因于业务代码。部分导航回执超时但预约已保存，必须核对状态再重试。部分截图重名覆盖，不能作为每次尝试的独立图片。
