# 数据与隐私管理方案（课程草案）

系统仅初始化模拟数据，不在仓库放真实账号、密码、联系方式、证据或有效会话。本方案不编造法定期限或学校已批准制度；正式采集前由学校业务/数据负责人确认用途、告知、访问、归档、纠错、备份留存和到期处置授权。

|对象|必要用途|可见主体|更正与保留|
|---|---|---|---|
|主体编号、显示名、角色、培训与范围|识别责任、核验资格|本人必要资料；授权管理岗位|授权变更留审计；离岗停用不删除历史责任|
|预约与交接|时段承诺、实物及使用事实|本人；实验室范围管理员；只读汇总岗位|原事实不覆盖，不同内容重试拒绝；追加说明或异常异议|
|异常与证据|故障核实、损坏争议与维修|报告人、关联借用人、范围管理员、指派维修人|附件鉴权、摘要、大小及可读性校验；可读不等于恶意扫描，真实材料另需学校扫描方案|
|维修与验收|责任指派和复测|当前执行人及范围管理员；本人只展示必要进度|改派保留事件，维修执行人不得自行验收|
|审计|追踪原/新状态、操作者、原因及关联请求|授权审计岗位|只追加；受控更正补事件；保留期限待批准，普通用户不能删改|
|消息与日志|业务提醒、故障排查|本人消息、授权运维最少日志|不记录凭据或消息供应商完整响应；失败人工联系追加留痕|
|备份|故障恢复|受控备份/恢复人员|排除会话、核验摘要；独立存储、访问及加密由平台确认；期限不等同日志期限|

受控更正：本人提出异议或补证→另一名有范围且非报告人/借用人的管理员独立复核→追加结论和依据→通知相关人。当前不自动判赔，不改写原交接/审计。涉及身份映射更正、机构数据导出、正式匿名化/删除及跨备份到期处置，还须受控工单和学校政策；未提供自助批量删除审计或证据的后门。正式制度确认前AUD-0033保持等待制度确认。
