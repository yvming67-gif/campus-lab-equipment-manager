# 角色工人与实体目录

组织边界与软件边界分别判断。维修支持暂列组织外协作；若将来证实为中心内岗位，应移入业务工人目录，系统维修角色和权限无需随之改变。

|角色|组织归属|当前职责|业务身份|系统身份|权限|依据|
|---|---|---|---|---|---|---|
|学生|中心外|申请设备、接受交接、归还、报告异常及追加本人关联回应|外部业务执行者|系统主要参与者|设备及本人记录，无整间场地申请权；关联异常可回应但不可核实|SRC-A01/A02/D02|
|教师|中心外|设备借用及整间场地负责、开始结束交接、追加本人关联异常回应|外部业务执行者|系统主要参与者|设备、本人场地及本人记录；关联异常可回应但不可核实|SRC-A01/D02|
|实验室管理员|中心内（假设）|审批、核验、实物交接、异常核实、维修验收、整理资料|业务工人BW-01|系统参与者|授权实验室；不得审批本人；验收不同于维修执行|SRC-D01/D02|
|维修支持岗位／维修人员|中心外协作（待核实）|接受指派、技术维修、提交结果|外部协作参与者；维修活动承担者|维修人员TECHNICIAN|仅被指派工单及必要证据；不能自验收|SRC-D01/D02|
|实验教学中心主任|中心内（假设）|确认业务目标、监督责任、复核并提供利用信息|业务工人BW-02、业务负责人|只读系统参与者DIRECTOR|全中心统计与审计；无隐含审批借还权|SRC-D01；代码角色|
|教学管理部门|中心外（待核实）|提出利用信息需求、接受经主任复核的汇总|外部信息接收者|无直接系统身份|本期不配置其账号；与主任不是同一主体|AS-02/06|
|系统管理员|技术支撑归属待核实|维护身份映射、角色、范围、资质、日历和参数|支持岗位BW-03，不是对外服务目标|系统参与者SYS_ADMIN|配置与只读审计；无自动业务审批借还权|SRC-D02/E01|
|学校统一身份认证系统|软件外；学校组织内|提供认证断言或身份映射结果|软件支撑，不列现状业务价值接收者|外部系统参与者|仅认证接口；当前演示为独立模拟提供方|SRC-A01/E01|
|消息服务|软件外；供应方待定|接受投递任务并返回投递结果|通知渠道，不是业务工人或价值接收者|外部系统参与者|无审批或业务状态写权；演示渠道不等于真实送达|SRC-D02/E01|

## 业务实体与载体

|编号|对象|载体|主要信息|状态|维护者|凭据|数据去向|
|---|---|---|---|---|---|---|---|
|BE-01|设备|实物；可能放于保管柜|标签、名称、配件、实际地点和状态|在库／借出；安全可服务条件另记|管理员与实际借用人|借出和归还凭据|Resource/EquipmentDetail；柜子只记交接地点|
|BE-02|场地|实际空间|位置、容量、现场条件|未使用／实际使用中；安全限制另记|管理员、负责教师|入场与结束记录|Resource/RoomDetail；不等于预约记录|
|BE-03|纸质申请材料|纸表，题设载体|申请人、对象、用途、时段；实际字段待查|提出／已处理（载体写法待核实）|申请人、管理员|审批意见或通知|数字化为申请与补充说明；不按纸张一表一数据库表|
|BE-04|共享预约表|共享表格，题设载体|设备与计划时段、处理结果；具体列未知|人工更新；无证据证明具备排他保护|管理员|申请材料与决定|预约记录、决定、日历；只迁移信息职责|
|BE-05|设备借还登记册|独立纸质或人工登记，AS-03|设备标签、借还时间、借用人与配件核对|借出／已接收；原载体状态待核实|管理员|实物交接|Loan/ReturnRecord/HandoverItem；与柜子分离|
|BE-06|场地申请与使用记录|现状载体待核实，AS-04|负责教师、时段、人数、实际开始结束|申请／决定／实际使用事实分开|管理员、负责教师|入场和离场核验|Reservation/RoomUse；不是场地本体|
|BE-07|异常记录|纸表、消息或其他载体待核实|现象、时间、资源、关联使用与证据|待核实／处置结论（现状术语未知）|报告人、管理员|原交接及核实依据|Incident/Evidence/IncidentResponse|

|BE-09|利用信息汇总|人工汇总及报表，AS-06|计划、实际、开放和维护时间及口径|整理／复核／提供|管理员、主任|原申请、借还、场地、维护资料|由历史事实派生报表，不虚构独立汇总实体表|
