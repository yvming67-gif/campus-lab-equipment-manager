# 业务用例与业务实现

SP-01恢复资源可服务条件是支持性过程，支撑BUC-05及后续BUC-01/04服务，不以维修人员参与就把维修人员当作唯一受益者。

## BUC-01 获得设备预约结果

组织边界：某高校实验教学中心。主要业务执行者：学生、教师。其他协作：实验室管理员（内部）。服务对象与受益者：申请人及安排课程的教师。

触发：提出指定设备和时段的使用需要。对外结果：收到明确预约决定；获准者得到可核对的时段承诺与领取条件，未获准者得到原因。业务价值：使使用计划有可追踪的承诺依据。

内部岗位：BW-01；业务实体：BE-01/03/04/10。边界：止于预约结果，不包括实物交付；登录、自动检查是实现职责。

现状：AS-E01至AS-E07；改进：TO-E01至TO-E07。系统承接：UC-01,UC-02,UC-03,UC-04,UC-06,UC-07,UC-08,UC-18,UC-19,UC-20,UC-22,UC-23,UC-26,UC-27。

## BUC-02 完成设备领取

组织边界：某高校实验教学中心。主要业务执行者：学生、教师。其他协作：实验室管理员（内部）。服务对象与受益者：获准借用人与下一位申请人。

触发：获准借用人到场领取。对外结果：实物、配件及责任完成交接；不能交付时得到可核实原因和协调结果。业务价值：使预约承诺转化为安全、可追责的实际使用。

内部岗位：BW-01；业务实体：BE-01/04/05/10。边界：领取不是预约批准；止于实际交付或明确拒绝/协调。

现状：AS-E08至AS-E10；改进：TO-E08至TO-E11。系统承接：UC-09,UC-27。

## BUC-03 完成设备归还

组织边界：某高校实验教学中心。主要业务执行者：学生、教师。其他协作：实验室管理员（内部）。服务对象与受益者：借用人、设备保管人与后续申请人。

触发：借用人交回设备。对外结果：形成真实接收凭据及配件结论；逾期、缺件、损坏另留事实。业务价值：结束实物责任交接并为下一次可用判断提供依据。

内部岗位：BW-01；业务实体：BE-01/05/07。边界：接收成功不自动证明设备安全；维修另属支持过程。

现状：AS-E11至AS-E13；改进：TO-E12至TO-E15。系统承接：UC-10,UC-26。

## BUC-04 获得场地使用服务

组织边界：某高校实验教学中心。主要业务执行者：教师。其他协作：实验室管理员（内部）。服务对象与受益者：负责教师与参加活动人员。

触发：教师提出整间场地活动需要。对外结果：获得场地决定，获准后按实际入场与结束检查完成空间交接。业务价值：提供可负责、可协调的空间时段与使用事实。

内部岗位：BW-01；业务实体：BE-02/06/10。边界：不自动获得室内设备；设备另申请；场地开始结束独立于借还。

现状：AS-R01至AS-R10；改进：TO-R01至TO-R12。系统承接：UC-01,UC-02,UC-03,UC-05,UC-06,UC-07,UC-08,UC-11,UC-12,UC-18,UC-19,UC-20,UC-22,UC-23,UC-26,UC-27。

## BUC-05 获得资源异常处置结果

组织边界：某高校实验教学中心。主要业务执行者：学生、教师。其他协作：学校维修支持岗位（外部协作，归属待核实）；管理员（内部）。服务对象与受益者：报告人、受影响借用人及后续使用者。

触发：发现资源异常或对交接检查提出异议。对外结果：异常有核实结论、处置进度及结果；需要维修时保留技术处理与验收依据。业务价值：使安全问题得到明确责任和结果，而非仅转发报修消息。

内部岗位：BW-01；维修支持方；业务实体：BE-01/02/07/08。边界：恢复可服务条件是支持过程SP-01；维修人员是协作方，不是恢复价值的唯一接受者；不自动判赔。

现状：AS-M01至AS-M08；改进：TO-M01至TO-M12。系统承接：UC-13,UC-14,UC-15,UC-16,UC-17,UC-18,UC-22,UC-23,UC-25。

## BUC-06 获得资源利用信息

组织边界：某高校实验教学中心。主要业务执行者：教学管理部门（假设）。其他协作：管理员整理、中心主任复核（内部）。服务对象与受益者：教学管理部门与中心业务负责人。

触发：提出教学资源安排的信息需求。对外结果：获得计划与实际使用分列、口径和限制可解释的汇总信息。业务价值：支持教学资源配置判断，避免把预约量误当实际利用。

内部岗位：BW-01/02；业务实体：BE-04/05/06/08/09。边界：外部接收者不直接使用本系统；主任在软件查询后复核并提供；不承诺利用率已提升。

现状：AS-S01至AS-S06；改进：TO-S01至TO-S06。系统承接：UC-21,UC-24,UC-26。
