现状流程以题设为依据，没有已完成的学校访谈、问卷或现场观察；公开同类系统仅支持方案比较。14天、30分钟、8小时及配额等为课程约定，真实应用前需由目标组织确认。

高校共享实验资源的案例比较和设计决策见[案例研究与设计决定](../案例研究与设计决定.md)。其中外校的培训、迟到、授权和设备控制要求不直接作为本项目规则。

业务实体不与纸质载体或数据库表机械等同。可编辑UML在[图形源文件](../../models/图形源文件)，分析类、内部协作和状态模型见[分析模型目录](../课程规范完善/README.md)。软件只接管信息处理和规则执行，实物交接、现场检查、维修技术活动与人工责任仍由相应岗位承担。

网页和小程序复用同一需求基线；补充说明、异常报告、候选查询及回执契约见[接口与通道](../接口与通道.md)。前端展示结果不能代替执行时授权与状态复核。
