# 状态事件与规则字典

|维度|字段或派生位置|取值|含义|

## 业务规则

BR-01：只有已认证且有效的账号可访问受保护功能；模拟身份断言有效期60秒并校验会话随机量，回调只接受一次。

BR-02：学生和教师可预约设备；仅教师可预约整间场地。场地与设备独立占用，场地申请不自动占用或停用室内设备。 可移动设备独立；固定设备与关联场地另按BR-39校验。

BR-03：起始时间不得早于当前时间，结束时间不超过提交或批准时刻后14天；开始须早于结束。上述窗口为可配置课程参数。

BR-04：按Asia/Shanghai解释输入；时段采用左闭右开[start,end)，以30分钟为单位，同日使用，单次不超过8小时。相邻时段不冲突。

BR-05：预约时段必须完整位于实验室当日有效开放区间。默认每天08:00至20:00；日历保留生效与失效日期，变更不得损坏既有已确认承诺。

BR-06：资源服务状态为正常且实验室开放服务时才可承诺预约。异常隔离、维护中、停用或报废均不得预约或开始使用。正常服务但实物正在使用的资源，可预约计划结束后的时段；逾期未完成使用时禁止新增承诺。

BR-07：同一资源两份已确认或使用中预约不得重叠；重叠条件为new.start<old.end且new.end>old.start。批准时在事务中复核并由数据约束兜底。

BR-08：待审核不占用资源时段，不保证优先权；竞争申请可以同时待审核。批准失败保留待审核并提示冲突，不生成虚假通过决定。

BR-09：按执行时刻统计starts_at晚于当前且状态PENDING或CONFIRMED的未开始预约：每人设备最多3项，教师场地另计3项。PENDING也计数；已达计划开始、使用中及终态不计未来。批准/复核排除本条自身后再校验，不重复计数。被复核项已到计划开始时，不新增未来配额，不因其它合法未来项已达上限而拒绝该项复核；其它现行交接条件仍须满足。

BR-10：同一人在任一时刻已确认或使用中的设备预约最多3项；实际同时未归还设备也最多3台或套。每个可识别设备单独预约。

BR-11：同一教师重叠时段只能负责一间场地，待审核也纳入此项个人限制；可同时预约设备，设备数量按BR-10控制。

BR-12：存在逾期未归还设备或逾期未结束场地使用时，账号不得新建或获批预约，也不得再次领取或入场；已归还的历史逾期不永久封禁账号。

BR-13：需培训的设备在提交、批准与借出时均复核资格，资格未撤销且有效期覆盖预约结束时间。

BR-14：普通设备规则检查通过后自动确认并记录系统决定；高价值、危险、需培训设备及所有场地均人工审核。

BR-15：人工决定仅针对待审核，由具有该实验室授权的管理员执行；不得审批本人申请。通过或驳回均记录原因，过期页面版本须刷新。

BR-16：本人可在预约开始前取消待审核或已确认预约并说明原因。开始后或使用中不得按取消处理，须办理交接或异常处置。

BR-17：已确认预约在开始后30分钟内且尚未到结束时刻可开始使用。待审核到开始时失效；已确认超过宽限或到结束仍未开始则失效。扫描任务最多延迟60秒，交接检查即时执行。

BR-18：开始使用前须无同一资源尚未完成的实际使用。计划时段无冲突不替代现场检查；逾期和未交接阻止下一次实物交付或场地入场。

BR-19：设备借出须核验申请人学校编号、设备标签、配件与状态；异常则不生成借出凭据并隔离资源。保存到场、开始办理、实际交付时间及配件快照。

BR-20：设备归还必须存在对应借出凭据并核验标签，检查设备与每项配件。逾期、损坏或缺件仍保存真实归还事实，同时记录逾期与异常，不得伪造正常归还。无借出记录时转异常核查。

BR-21：场地开始与结束由授权管理员登记，核验负责教师及容量，结束时检查场地；实际提前结束释放剩余计划占用，原计划与实际时间分别保留。设备提前归还同理。

BR-22：异常必须记录可核查事实并由管理员核实；是否暂时阻断按BR-37分级。核实确认、排除或无需维修处置结案均留依据；未解决阻断异常不因另一工单完成而解除。

BR-23：确认异常才可创建维修工单，同一异常最多一张未关闭工单。维修占用立即取消相关未开始预约并通知；正在使用者保留使用事实，追加召回通知。

BR-24：仅当前被指派维修人员可接单、追加过程与提交结果；待验收不等于恢复。管理员验收通过关闭工单，失败退回处理中；当前指派人及曾实际接单、记录维修过程或提交结果的人均不得验收该工单，重新指派不清除职责回避。仅创建或重指派的管理动作不视为实际维修。

BR-25：资源状态由手工停用/报废限制、未关闭工单、未解决异常依次判定；只有全部解除后恢复正常。恢复正常不代表实物已在库，实际交接仍受BR-18限制。

BR-26：预约、审批、借出、归还、场地使用、异常和维护等关键变化保存原状态、新状态、操作者或系统主体、时间、原因和请求编号；业务界面不可改删，审计记录数据库层只追加。

BR-27：关键状态、事实、审计及站内通知/外部投递任务在一个事务内保存，失败整体回滚。外部投递在提交后独立执行，不回滚成功业务。

BR-28：站内通知即刻保存，外部首次失败后按1、5、15分钟间隔重试最多3次；投递去重、租约恢复中断任务。重试耗尽留失败状态并允许追加人工联系结果；到期前1小时提醒，逾期每天一次。

BR-29：普通用户只看本人预约、使用与通知；管理员按实验室范围管理；维修人员只处理被指派任务及相关证据；主任只读全中心统计与审计；系统管理员维护角色与配置，不因此获得审批或借还权限。

BR-30：用户角色、管理范围与培训资格仅系统管理员维护并留依据；停用和撤权后后续请求重新检查权限，禁止撤销本人最后的系统管理能力。

BR-31：实验室、资源与业务凭据有唯一编号；设备标签、资源类型与所属实验室建立后不可直接变更。设备与场地各有且仅有对应类型明细，历史使用资源不物理删除。

BR-32：异常证据只允许PNG、JPEG或PDF，最大5MB，校验扩展名及文件头，保存摘要和上传主体。读取须经对象权限校验并记审计，以附件下载而非公开静态链接提供。

BR-33：规则参数有版本、依据与提交快照。提交和初始批准执行当前申请规则；实际开始重核当前身份、角色、培训、资源服务、有效开放、复核标志、原领取截止、实际占用及同时借用限制。原计划不按开始时刻当作新申请重算；参数变化不回写历史。周开放变更未来生效，单日例外按BR-40处理。

BR-34：实际利用率=正常服务且开放区间内实际使用时数/可服务时数。分子分母同口径裁剪，计划占用单列，分母为零标不适用；统计区间限过去31天。

BR-35：相同申请人及请求标识只生成一份预约，相同标识不同内容拒绝。批准、借出、归还和场地交接重复请求返回既有结果，不覆盖原事实；配件主档变更不改写交接快照。

BR-36：风险或资格要求变化后暂停未开始使用预约的交接；CONFIRMED保留原时段占用，开始前按BR-09继续占未来配额。有范围且非本人管理员追加复核；通过须核验现行条件及原领取截止，不通过明确取消释放；原审批决定不覆盖。

BR-37：普通无关联报告先待核实且不自动隔离；管理员报告、使用中关联安全事件和已核实异常阻断服务。核实、驳回、修复与受影响预约通知均留痕，不自动免除其他限制。

BR-38：可核实同资源前序延误且本人原宽限内到场时，管理员可记录等待，将领取截止放宽至原预约结束前；原结束不延长，不伪造前序归还，原时段占用保持。已到计划开始的等待项不属于BR-09的未来项，实际同时使用上限继续适用；协调取消另记事件。

BR-39：固定设备必须关联同实验室场地；与他人场地预约的重叠使用双向互斥，同一教师的配套场地与设备可并用。可移动设备独立借用，取放位置单独说明。

BR-40：单日开放例外优先于每周日历，同日仅一生效版本；闭馆或缩短时段须标记并通知受影响预约，禁止交接，使用中保留事实并通知现场处置。

BR-41：同一实验室可授权多名管理员备岗；待审核超过24小时或距开始不足1小时按日去重提醒有范围管理员，未获批到开始时仍依原规则失效。

BR-42：相关报告人及借用人可追加确认、异议或补充；独立复核由非报告人且非借用人的有范围管理员执行。事实和审计只追加，不自动判赔，不赋予借用人内部维修操作权。

BR-43：非关闭工单可由有范围管理员重新指派给当前有效维修人员，历史责任、原过程和指派原因保留，新指派人获得任务访问权。

BR-44：借出及入场重新检查账号、当前角色与培训；权限撤销影响未来预约并通知。实际归还和离场仍可由管理员如实接收；时段空闲不等于本人具有资格。

BR-45：同内容重试返回原凭据；内容不同的重复交接明确拒绝，不静默覆盖。参数版本错误返回业务错误；提示采用实际配置，列表以稳定排序分页并保留筛选。

BR-46：演示与正式身份、消息渠道明确隔离；正式配置缺失安全拒绝。外部消息稳定投递键重试，失败不能回滚业务；小程序本地退出不依赖远端可用性。
