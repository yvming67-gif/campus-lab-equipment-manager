面向高校实验教学中心的课程演示项目。学生和教师通过网页或原生微信小程序查询资源、申请预约和查看进度；管理员通过网页处理审批、交接、异常和维修。两端复用Django领域服务与PostgreSQL业务记录。

> 使用模拟身份、资源与业务数据。免费云端闲置后会休眠，首次打开可能等待约一分钟；额度耗尽时接受服务暂停。微信公开版与网页分别管理，当前入口及访问条件见[项目入口](docs/项目入口.md)。真实学校认证、外部消息和正式发布不能由演示结果替代，详见[已知限制](docs/已知限制.md)。

## 角色与能力

| 使用者 | 可完成的主要工作 |
| --- | --- |
| 学生、教师 | 查询设备和场地、选择候选时段、申请与取消、本人进度、补充说明、异常报告及通知 |
| 实验室管理员 | 管理范围内的预约审核、风险复核、设备借还、场地交接、异常核实、维修指派与验收 |
| 维修人员 | 有权维修任务的过程记录与结果提交；不能替代独立验收 |
| 系统管理员 | 用户角色、培训、基础参数和开放日历；不自动拥有业务审批权 |
| 实验教学中心主任 | 中心统计与只读审计 |

管理操作在网页办理。小程序是师生渠道，不提供管理员审批入口。申请、审批与实物交接分别留存，计划结束不等于实际归还。

## 快速开始

### 在线网页

打开[校园实验资源中心](https://campus-lab-equipment-manager.onrender.com/)，在模拟身份入口选择账号。公开演示密码统一为 **`Demo@2026`**。

| 账号 | 角色 |
| --- | --- |
| `student`、`student2` | 学生 |
| `teacher` | 教师 |
| `admin` | 实验室管理员 |
| `tech` | 维修人员 |
| `sysadmin` | 系统管理员 |
| `director` | 实验教学中心主任 |

共享演示中的操作会影响其他访客，请只填写模拟内容，不上传真实隐私、账号凭据或责任证据。[按角色操作说明](docs/演示操作说明.md)

### Windows本机运行

1. 安装[Python 3.13 x64](https://www.python.org/downloads/windows/)，勾选“Add python.exe to PATH”。
2. 点击本仓库 **Code → Download ZIP**，完整解压。
3. 双击 **启动演示.cmd**。首次需联网、约2GB可用磁盘，并下载约364MB的PostgreSQL组件；无需预装Git、Node.js或数据库服务。
4. 使用启动窗口显示的地址，默认 `http://127.0.0.1:8000`；端口占用会自动选择空闲端口。

保留启动窗口；按 `Ctrl+C` 停止网页与后台，双击 **停止数据库.cmd** 停止本项目数据库。再次启动保留数据；私有配置在不提交的 `.local`，依赖在 `.venv`。[运行指南](docs/运行指南.md) · [已有PostgreSQL及开发检查](docs/开发与验证.md)

### 微信小程序

微信公开版尚在准备，实际平台条件见[微信发布说明](docs/微信发布说明.md)。源码在 `miniprogram`，公开配置使用 `touristappid` 占位；开发者在私有副本绑定账号。后端地址由开发配置固定，登录者不能更改。[小程序开发指南](miniprogram/README.md)

## 业务约定

- 学生和教师可申请设备，仅教师可申请整间场地；可移动设备独立预约，固定设备遵守关联场地限制。
- 普通设备规则检查后自动确认；受限设备与场地人工审批。待审核不占时段，但计入个人未来配额，批准前重新检查。
- 默认未来14天、30分钟粒度、同日最长8小时；按开放日历执行。每类未来预约最多3项，同时最多使用3台或套设备。
- 候选时段只是查询快照。资源、资格、冲突与配额由服务端在提交和批准时重新核验。
- 实际交接与计划分开记录；异常分级核实，维修执行与验收分离，恢复前检查全部限制。
- 状态历史只追加。站内通知与业务同事务保存，外部消息失败不得撤销已保存业务；未知结果重试保留原请求标识。

这些属于课程基线，不能据此推定某所学校已有同样制度。[需求与规约](docs/逻辑整改/README.md) · [接口契约](docs/接口与通道.md)

## 技术与维护

Python 3.13 / Django 5.2 / PostgreSQL 17，网页采用Django模板，小程序采用原生JS/WXML/WXSS。常规网页运行无需前端构建。

```text
core/          领域服务、权限、接口、任务及测试
templates/     网页模板
static/        样式、交互与实景参考照片
miniprogram/   师生原生微信端
docs/          正式分析、模型说明、运行与验证文档
models/        ERD及可编辑UML源文件
tools/         启动、校验、备份及恢复工具
```
