# 微信小程序用户端

原生微信小程序，支持学生与教师查询设备/场地、提交预约、取消未开始预约、查看进度、读取通知及本人额度。管理员继续使用同仓库的Django网页。两端共用PostgreSQL及事务服务；数据来自后端。

## 本地运行

1. 先按仓库README启动后端：双击项目根目录`启动演示.cmd`，等待“启动成功”，记录显示的地址。
2. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，按工具提示登录。
3. 导入**本目录`miniprogram`**，选择“小程序”。已有AppID可填自己的公开AppID；课程演示可在工具提供的测试号/游客入口创建项目。仓库中的`touristappid`为占位值，不是注册的小程序账号。如当前工具版本限制游客网络调试，请切换到工具测试号或自己的AppID。
4. 在开发者工具“详情→本地设置”启用本地调试的“不校验合法域名、TLS版本及HTTPS证书”。项目配置中的`urlCheck:false`仅用于本地调试。
5. 编译后选择学生或教师，填写演示密码`Demo@2026`。服务地址填后端启动窗口中的地址，默认`http://127.0.0.1:8000`；端口自动变化时在登录页同步修改。

前端使用原生JS/WXML/WXSS，没有npm构建步骤，也不需要云开发环境、AppSecret或微信支付。模拟身份登录用于课程演示，没有接入真实学校认证或`wx.login`账号绑定。

## 演示流程

- 学生查询普通设备，选取未来开放日期、30分钟粒度的时段，填写用途并提交，观察自动确认及通知。
- 查询“协作机器人平台”等受限设备，提交后为待审核。在网页用`admin`审批，再回到小程序刷新详情，观察同一预约的状态和通知变化。
- 在详情中填写原因，取消尚未开始的本人预约；查看取消后的时段释放。
- 学生可查询场地信息；整间场地申请仅对教师开放。切换到`teacher`申请，审批仍由网页管理员完成。
- 在“通知”中查看预约结果、读单条或全部标为已读；在“我的”查看设备/场地分别计数的额度。

模拟账号：`student`、`student2`、`teacher`。管理账号不在此客户端办理业务。小程序的“通知”读取系统内通知，不触发微信订阅消息授权。

## 目录

- `app.json`：七个页面、四个底部导航及窗口配置。
- `pages/`：登录、资源目录、资源预约、本人预约、预约详情、通知、我的。
- `controllers.js`：各页面交互与数据状态。
- `utils/api.js`：服务地址、专属会话、错误展示及请求幂等；认证凭据仅通过Authorization头传递。
- `utils/format.js`：中国时区日期、时段和状态展示。
- `../tools/mini-check/client.test.cjs`：客户端会话、身份边界、防重复提交和交互契约测试。
- `project.config.json`：可导入的本地开发配置；个人AppID及工具设置建议放在不提交的`project.private.config.json`中。

关闭小程序后保留两小时内的本机演示会话；退出会在后端撤销该会话。失败的提交保留请求编号及草稿，原内容重试不会重复创建预约；服务地址或身份切换会清除旧会话及草稿。

## 验证

普通运行无需Node.js。进行源码维护时可使用Node.js 20及以上版本：

```powershell
node --test tools/mini-check/client.test.cjs
npm ci --prefix tools/mini-check --ignore-scripts --no-audit --no-fund
node tools/mini-check/compile.cjs
```

以上命令在仓库根目录执行。编译检查使用微信团队测试工具所依赖的`miniprogram-compiler@0.2.3`，验证基础WXML/WXSS语法；最终仍应在当前微信开发者工具及目标微信版本中验证。

后端接口、权限与验收范围见[微信小程序扩展说明](../docs/微信小程序扩展说明.md)。已完成的验证与未覆盖环境以仓库测试记录为准，不把浏览器渲染等同于微信容器或真机测试。

## 使用边界

本地后端默认只监听本机回环地址。开发者工具模拟器可连接同一电脑上的该地址；手机上的`127.0.0.1`指向手机自身，扫码预览不能据此访问电脑后端。

正式预览、真机和发布需要可用AppID、可访问的HTTPS后端与合法域名配置，并完成正式身份适配、部署和平台审核。当前交付范围为课程本地演示，不包含这些平台发布工作。
