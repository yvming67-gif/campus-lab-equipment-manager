# 校园实验资源中心 · 微信小程序用户端

原生微信小程序，支持学生与教师查询设备和场地、提交预约、取消未开始预约、查看进度、补充申请说明、报告资源异常、读取通知及本人额度。管理人员继续使用同仓库Django网页。两端共用PostgreSQL及事务服务；数据来自后端，采用公开模拟身份。项目全称仍为“校园实验室设备预约与借用管理系统”。

## 连接现有云端演示

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，按工具提示登录。
2. 导入本目录`miniprogram`，选择“小程序”。仓库`project.config.json`中的`touristappid`是占位值。导入时使用自己的测试号或可用AppID；个人工具设置保存在不提交的`project.private.config.json`中。
3. 本版本由开发者在`config.js`中固定连接`https://campus-lab-equipment-manager.onrender.com`。登录页不提供地址输入，旧版地址缓存不再生效。
4. 本地调试可在“详情→本地设置”启用“不校验合法域名、TLS版本及HTTPS证书”；公开配置默认开启`urlCheck:true`，连接已配置的云端域名。仅在自己的本机开发副本临时关闭检查，发布前恢复开启并重新验收。
5. 选择学生或教师，填写公开演示密码`Demo@2026`后登录。管理角色不在小程序办理业务。

Render免费实例闲置后可能休眠，首次唤醒时连接可能超时；稍候重试，勿更改服务地址。已发出的预约若结果未确认，应保持原内容重试或先查看本人记录。

## 开发者连接本机后端

1. 按仓库README启动后端，记录启动窗口给出的实际地址和端口。
2. 在自己的开发副本中将`config.js`的`backendBaseUrl`改为该地址，例如`http://127.0.0.1:8000`，重新编译。端口变化时修改开发配置并重新编译。
3. 同机开发者工具可使用回环地址；手机上的`127.0.0.1`指向手机自身。真机预览使用手机可访问的HTTPS后端。
4. 提交代码前恢复公共云端地址。不得把数据库连接串、AppSecret或其他凭据加入小程序包。

配置仅接受HTTPS源站或本机回环HTTP地址。会话、未确认提交草稿与当前服务源站绑定；来源不同或无来源的旧版会话失效并清除草稿，要求重新登录。已成功创建的后端预约不受本地缓存清理影响。

## 体验版与平台资料

目标为所有人可访问的正式版本，当前1.4.0已设体验版，尚未正式发布。[发布状态与条件](../docs/微信发布说明.md)。体验版、名称头像、合法域名、备案、上传和正式发布分别管理，修改页面标题不能改变微信列表资料。

本地调试的关闭域名检查仅用于开发，不作为体验版可访问的证明。手机微信胶囊页面才属于小程序，浏览器网址栏页面是网页。iPhone暂不开展验收，Android验证范围见[验证说明](../docs/验证说明.md)。

## 功能与源码

八个原生页面包括登录、资源目录、资源预约、本人预约、预约详情、通知、个人信息和异常报告。候选时段可带入申请，待审核时可追加说明；异常报告只记录文字事实，网页处理核实、附件和维修。管理人员继续在网页审批、交接与验收。

`controllers.js`组织交互，`utils/api.js`处理固定源站、专属会话、错误和幂等，`utils/format.js`统一北京时间。请求令牌只放Authorization头，不进入URL、分享链接或二维码。退出清理本机凭据，未知结果先核对回执；身份变化不恢复旧用户草稿。

正文与长表单使用实色，透明层只用于少量区域；“我的”可简化透明与动态效果。主要触控区采用逻辑像素设计。三张实景照片随包发布，不请求第三方图片域名；来源与权利见[图片来源](../docs/图片来源.md)。

## 源码检查

常规客户端使用无需安装Node.js。开发者在仓库根目录执行：

```powershell
node --test tools/mini-check/*.test.cjs
npm ci --prefix tools/mini-check --ignore-scripts --no-audit --no-fund
node tools/mini-check/compile.cjs
```

模板检查采用miniprogram-compiler@0.2.3，不能替代微信原生运行或手机验证。所有接口仍复用领域服务；[扩展说明](../docs/微信小程序扩展说明.md)与[接口契约](../docs/接口与通道.md)记录权限、状态及回执边界。
