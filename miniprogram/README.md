# 校园实验资源中心 · 微信小程序用户端

原生微信小程序，支持学生与教师查询设备和场地、提交预约、取消未开始预约、查看进度、读取通知及本人额度。管理人员继续使用同仓库Django网页。两端共用PostgreSQL及事务服务；数据来自后端，采用公开模拟身份。项目全称仍为“校园实验室设备预约与借用管理系统”。

## 连接现有云端演示

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，按工具提示登录。
2. 导入本目录`miniprogram`，选择“小程序”。仓库`project.config.json`中的`touristappid`是占位值。导入时使用自己的测试号或可用AppID；个人工具设置保存在不提交的`project.private.config.json`中。
3. 本版本由开发者在`config.js`中固定连接`https://campus-lab-equipment-manager.onrender.com`。登录页不提供地址输入，旧版地址缓存不再生效。
4. 本地调试可在“详情→本地设置”启用“不校验合法域名、TLS版本及HTTPS证书”；`urlCheck:false`仅用于开发调试。正式发布应配置平台要求的合法域名并重新验收。
5. 选择学生或教师，填写公开演示密码`Demo@2026`后登录。管理角色不在小程序办理业务。

Render免费实例闲置后可能休眠，首次唤醒时连接可能超时；稍候重试，勿更改服务地址。已发出的预约若结果未确认，应保持原内容重试或先查看本人记录。

## 开发者连接本机后端

1. 按仓库README启动后端，记录启动窗口给出的实际地址和端口。
2. 在自己的开发副本中将`config.js`的`backendBaseUrl`改为该地址，例如`http://127.0.0.1:8000`，重新编译。端口变化时修改开发配置并重新编译。
3. 同机开发者工具可使用回环地址；手机上的`127.0.0.1`指向手机自身。真机预览使用手机可访问的HTTPS后端。
4. 提交代码前恢复公共云端地址。不得把数据库连接串、AppSecret或其他凭据加入小程序包。

配置仅接受HTTPS源站或本机回环HTTP地址。会话、未确认提交草稿与当前服务源站绑定；来源不同或无来源的旧版会话失效并清除草稿，要求重新登录。已成功创建的后端预约不受本地缓存清理影响。

## 手机测试号预览

1. 扫描开发者工具生成的本项目预览二维码，确认右上角为微信胶囊按钮，避免把手机浏览器网页误当作小程序。
2. 新预览自动使用开发者配置的云端地址，无需填写地址。旧预览仍保留旧界面，应退出后扫描新二维码。
3. 本测试号联调需在小程序右上角“···→开发调试→打开调试”后，退出并重新进入再登录。当前真机通过范围仅限调试模式，不能据此声称非调试模式或正式发布已验收。规则见微信官方[网络能力](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。
4. 使用模拟学生或教师账号。网页能打开不能单独证明小程序网络校验通过；失败时检查手机网络、服务唤醒及调试设置。

前端使用原生JS/WXML/WXSS，没有npm构建步骤，无需云开发环境、AppSecret或微信支付。模拟身份没有接入学校真实认证或`wx.login`绑定。

## 名称和图标

页面品牌和登录导航标题为“校园实验资源中心”。图标使用墨绿底、白色烧瓶与预约勾选：

- `assets/brand-icon.svg`：可编辑矢量源文件。
- `assets/brand-icon.png`：1024×1024不透明PNG，供页面显示及平台头像上传。
- `config.js`：页面品牌名和开发者维护的后端地址。
- `app.json`、`pages/login/index.json`：原生窗口与登录页导航标题。

微信列表中的账号名称、头像由微信平台账号资料控制，不由`projectname`或页面标题设置。当前测试号未找到可编辑入口，平台资料未修改；代码内品牌与平台账号资料的完成状态分别记录。正式账号具备相应编辑入口后，可使用同一名称和PNG文件，并按平台要求完成审核。

## 演示流程

- 学生查询普通设备，选未来开放日期和30分钟粒度时段，提交后观察自动确认及通知。
- 申请受限设备，观察待审核；网页管理员审批后，小程序刷新同一预约显示结果与过程记录。
- 填写原因取消尚未开始的本人预约，确认状态、通知和时段释放。
- 学生可查询场地但不能申请整间实验室；教师场地申请由网页管理员审批。
- “通知”读取本人站内通知，可单条或全部标为已读；“我的”分别显示设备、场地额度。

模拟账号为`student`、`student2`、`teacher`。通知功能不触发微信订阅消息授权。

## 源码和验证

`pages/`包含七个页面；`controllers.js`负责交互；`utils/api.js`负责固定源站请求、专属会话、错误反馈和请求幂等；`utils/format.js`负责中国时区日期与状态展示。认证令牌只放Authorization头，不进入URL。

关闭客户端保留两小时内的有效本机会话；退出时尝试撤销后端会话，无论网络是否成功均清理本地凭据并返回登录。未确认的提交保留请求编号和草稿，相同内容重试复用原请求编号。身份或开发配置变化会使旧草稿失效。

普通运行无需Node.js。源码维护时在仓库根目录执行：

```powershell
node --test tools/mini-check/client.test.cjs
npm ci --prefix tools/mini-check --ignore-scripts --no-audit --no-fund
node tools/mini-check/compile.cjs
```

模板检查使用微信团队测试工具所依赖的`miniprogram-compiler@0.2.3`，不能替代微信容器和真机测试。接口与规约见[扩展说明](../docs/微信小程序扩展说明.md)，分阶段实际证据见[容器与真机验收记录](../docs/整改/微信容器与真机验收-2026-10-23.md)。Android旧预览已完成核心业务闭环；本次品牌与连接配置更新另行记录复验。iPhone和正式发布未验收，详见[外部依赖](../docs/整改/待确认与外部依赖.md)。
